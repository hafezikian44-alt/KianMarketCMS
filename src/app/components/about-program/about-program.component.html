معرفی پروژه

Kian Market یک پنل مدیریت فروشگاه اینترنتی است که با Angular 16 توسعه داده شده و با هدف تمرین مفاهیم توسعه فرانت‌اند، مدیریت داده‌ها و ارتباط با REST API پیاده‌سازی شده است.

تکنولوژی‌های استفاده‌شده

Angular 16 TypeScript RxJS NgModule HTML5 CSS3 Bootstrap DummyJSON API

ساختار و معماری

پروژه بر پایه معماری NgModule توسعه داده شده و شامل دو ماژول اصلی Products و Users است. در این پروژه از Angular Signals استفاده نشده است.

API و مدیریت داده‌ها

برای ارتباط با سرور از DummyJSON به عنوان یک REST API آزمایشی استفاده شده است. عملیات ایجاد، ویرایش و حذف در این سرویس شبیه‌سازی می‌شوند و تغییرات به صورت دائمی روی سرور ذخیره نمی‌شوند.

هوش مصنوعی در توسعه

در طراحی اولیه رابط کاربری از ChatGPT (OpenAI - GPT-6) برای تولید قالب‌های HTML و CSS کمک گرفته شده است. این قالب‌ها سپس توسط توسعه‌دهنده شخصی‌سازی و حدود ۴۰ درصد ویرایش شده‌اند.
